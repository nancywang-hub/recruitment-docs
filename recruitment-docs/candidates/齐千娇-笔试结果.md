# 智能水印防护系统

## 项目简介

本项目实现了一个面向AIGC的智能水印防护系统，通过**结构化水印**和**对抗性扰动**的有机结合，生成难以被AI工具（Stable Diffusion Inpainting）去除的水印，有效保护数字内容的版权。

## 主要特性

- **结构化分层水印**：将Logo智能分解为主碎片、特征碎片和干扰碎片
- **对抗性扰动**：针对AI修复模型的梯度攻击，增加去除难度
- **智能放置策略**：基于图像高频区域和边缘检测自动选择最佳位置
- **策略可配置**：平衡、可辨识优先、防护优先三种策略可选
- **不可见溯源水印**：DCT域隐写水印，嵌入版权信息
- **完整验证流程**：提供与传统水印的对比测试和AI去除效果评估

## 系统架构

```
├── watermark.py          # 结构化水印生成器（核心）
├── adversarial.py        # 对抗扰动生成器
├── stegano.py           # 不可见隐写水印（修复版）
├── protect_image.py     # 主防护程序（整合水印+扰动）
├── verify.py           # 效果验证（对比传统水印）

```

### 基本使用

1. **生成防护水印**：
```bash
python protect_image.py --image images/input.jpg --logo images/logo.png --output results/protected.png
```

2. **验证防护效果**：
```bash
python verify.py --image images/input.jpg --logo images/logo.png --output-dir results
```

3. **测试AI去除**：
```bash
python test_inpainting.py --image results/protected.png --output results/ai_removed.png --compare --original images/input.jpg
```

4. **生成对抗性扰动水印**：
```bash
python adversarial.py --image images/input.jpg --output perturbed.png
```

5. **嵌入隐写（不可见）水印**：
```bash
python stegano.py --mode embed --image results/protected.png --output results/final_protected.png
```

6. **从图像中提取隐写水印**：
```bash
python stegano.py --mode extract --image results/final_protected.png
```

### 参数说明

```bash
# 策略选择
python protect_image.py --image images/input.jpg --logo images/logo.png --strategy secure
# 可选策略: balanced（默认）, recognizable, secure

# 不添加对抗扰动
python protect_image.py --image images/input.jpg --logo images/logo.png --no-perturbation

# 指定碎片数量
python protect_image.py --image images/input.jpg --logo images/logo.png --n-fragments 10
```

## 设计思路详解

### 1. 结构化水印设计

#### 设计目标
传统的边角水印容易被AI识别和去除。我们的结构化水印设计目标是：
- **提高去除难度**：将水印分散在图像多个区域
- **保持可辨识性**：人眼仍能识别版权信息  
- **智能化放置**：自动选择最佳放置位置

#### 三层结构设计

**1. 主碎片层（30%）**
- 功能：提供明确的版权标识
- 实现：完整Logo缩小版，放置在高频纹理区域
- 透明度：30-50%，旋转角度：-8°到+8°

**2. 特征碎片层（40%）**
- 功能：保留Logo的关键特征
- 实现：文字Logo提取字符，图形Logo分割轮廓
- 透明度：15-30%，贴合边缘方向放置

**3. 干扰碎片层（30%）**
- 功能：增加AI识别难度
- 实现：Logo小片段随机分布
- 透明度：8-20%，近乎隐形

#### 智能放置算法
- **高频区域检测**：使用Sobel算子和自适应阈值
- **边缘方向对齐**：根据局部梯度方向旋转碎片
- **避让平坦区域**：优先在纹理丰富区域放置

### 2. 对抗性扰动技术

#### 技术原理：PGD攻击
采用**投影梯度下降法**（PGD），在图像中添加微小扰动，使AI修复模型产生错误：

1. **损失函数**：最大化修复误差
   ```python
   loss = -MSE(AI修复结果, 原始图像)
   ```

2. **迭代攻击**：
   ```
   初始化扰动 δ
   for i in range(迭代次数):
      计算梯度 ∇L
      更新扰动: δ ← δ + α·sign(∇L)
      约束幅度: δ ← clip(δ, -ε, ε)
   ```

3. **关键技术**：
   - **梯度符号攻击**：使用sign()而非原始梯度
   - **掩码聚焦**：只在水印区域添加扰动
   - **幅度约束**：ε=0.03（人眼不可见）

#### 破坏检测机制
系统自动检测破坏性扰动特征：
- 高频噪声分析（拉普拉斯方差）
- 频域周期性检测（FFT分析）
- 异常边缘密度检测

当检测到破坏性扰动时，系统会警告用户AI去除可能导致图片损坏。

## 策略说明

系统提供三种预设策略：

| 策略 | 主碎片 | 特征碎片 | 干扰碎片 | 适用场景 |
|------|--------|----------|----------|----------|
| **平衡策略** | 30% | 40% | 30% | 通用场景，兼顾辨识与防护 |
| **可辨识优先** | 40% | 40% | 20% | 版权声明需要清晰可见 |
| **防护优先** | 20% | 30% | 50% | 高强度防护需求 |

## 技术难点与解决方案

### 1. 模型加载问题
**问题**：Stable Diffusion模型配置文件中存在null值
**解决方案**：编写`fix_model_completely.py`修复配置文件

### 2. DCT水印提取失败
**问题**：长度前缀解析错误导致提取失败
**解决方案**：重新设计比特序列结构，添加32位固定长度前缀

### 3. 对抗扰动效果不佳
**问题**：普通扰动对AI模型影响有限
**解决方案**：采用PGD攻击，针对inpainting模型特征设计损失函数

## 故障排除

### 常见问题

1. **模型加载失败**
   ```
   运行: python fix_model_completely.py
   确保: stable-diffusion-2-inpainting-main 目录存在
   ```

2. **内存不足**
   ```
   降低图像分辨率
   减少碎片数量: --n-fragments 6
   使用OpenCV模式: --use-opencv
   ```

3. **水印不可见**
   ```
   调整透明度参数
   检查Logo是否有alpha通道
   尝试recognizable策略
   ```
