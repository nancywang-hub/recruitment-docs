# 实战题 05：个人与企业AI本地大脑 - 智能数据驾驶舱

## 一、任务背景

在快速变化的商业环境中，个人、企业和组织普遍依赖各类办公OA（如钉钉、飞书、企微）、CRM、人事、财务等系统进行日常运营。然而，这些系统的数据往往是碎片化和割裂的，导致企业业务负责人和决策层难以快速获取清晰的数据洞察来辅助决策，员工也难以有效地沉淀和利用企业知识资产。现有工具虽然提供了数据报表，但缺乏深度智能分析和针对性的角色化展示。本项目旨在挑战你，作为一名AI工程师，设计并开发一个“AI本地大脑”原型，能够整合多源企业数据，构建企业知识库，并为不同角色提供个性化的智能数据驾驶舱（Intelligent Data Cockpit）。

## 二、核心任务要求

**提示**: 本任务旨在考察你对核心AI技术原理的理解、解决问题的思路以及工程实现能力。我们期望你交付一个功能原型，而非一个达到产品级或业界SOTA水平的复杂系统。在满足核心功能要求的前提下，允许在AI模型的智能程度和数据处理的复杂度上进行适当的简化，但需在`README.md`中明确说明你的权衡和设计选择。

你需要开发一个AI驱动的原型系统，模拟一个“AI本地大脑”，该系统能够接入并整合多源企业数据，构建企业知识库，并为至少两种不同类型的企业角色提供定制化的智能数据驾驶舱（Intelligent Data Cockpit）。

*   **输入**:
    *   **聊天交流记录**: 模拟或实际接入办公OA（如钉钉、飞书、企微）的聊天交流记录数据（可使用模拟数据或公开数据集，例如飞书或企微的聊天记录导出格式）。
    *   **其他经营管理数据**: 模拟或接入至少**一种**其他类型的经营管理类数据，例如：
        *   CRM数据（客户、销售机会、跟进记录）
        *   项目管理数据（任务、进度、成员）
        *   简单的财务数据（收支、成本）
        *   人事数据（员工信息、考勤）

*   **核心功能一：多源数据接入与智能知识融合**
    *   **数据接入**: 设计并实现数据接口或模拟数据加载机制，能够同时接入聊天交流记录和至少一种其他经营管理数据。
    *   **知识库构建**: 利用AI技术（如自然语言处理、信息抽取、RAG等）对接入的非结构化（聊天记录）和结构化数据进行处理，形成可查询、可概括、可分析的企业级知识库。知识库应能提取出关键信息、待办事项、决策点、常见问题等。

*   **核心功能二：角色化智能数据驾驶舱演示**
    *   **角色定义**: 为至少**两种不同类型**的企业角色（例如：业务负责人、销售经理、项目经理、HR负责人、普通员工等）设计其关注的核心业务痛点和需要的数据洞察。
    *   **驾驶舱构建**: 构建一个Web或GUI演示界面，能够：
        1.  允许用户选择或切换不同的角色。
        2.  根据所选角色，展示其专属的“智能数据驾驶舱”。
    *   **驾驶舱内容**: 每个驾驶舱应至少包含以下AI赋能的模块：
        1.  **关键信息总结与决策辅助**: 从知识库中提炼出与该角色直接相关的重要信息，如待办事项、潜在风险、项目最新进展、关键决策点等，并以简洁明了的方式呈现。
        2.  **趋势分析与AI洞察**: 基于所接入的数据，生成相关的业务趋势分析（例如，销售额变化、项目延期风险趋势、客户反馈热点等），并由AI提供初步的洞察和建议。
        3.  **智能问答与知识查询**: 允许该角色用户通过自然语言对企业知识库进行提问，即时获取所需的业务信息、策略、历史记录或相关文档链接。
    *   **(加分项)** **个性化推荐**: 根据当前角色和驾驶舱内显示的内容，AI能够主动推荐相关的文档、信息或建议。

*   **产出**:
    1.  一个可执行的、能演示上述至少两种角色驾驶舱功能的Demo应用。
    2.  一份`README.md`文档，详细说明设计思路、数据模拟/接入方案、AI技术选型、知识库构建方法、不同角色驾驶舱的设计逻辑，以及部署和演示效果。

## 三、推荐参考工具

**重要提示**: 本试题中给出的推荐参考工具和技术路线仅为帮助你快速上手和提供思路。我们鼓励你进行独立思考和探索，如果你发现有更优、更高效或更适合当前问题的解决方案，完全可以使用你认为更合适的方案作答，并在`README.md`中说明你的技术选型理由。

*   **NLP/RAG**:
    *   **大型语言模型 (LLMs)**: Llama-2-7b-chat (可本地部署), Qwen-1.5-7b-chat (可本地部署，中文能力强), 或通过API调用主流商用LLM。
    *   **嵌入模型**: BAAI/bge-small-zh-v1.5 (中文嵌入), sentence-transformers/all-MiniLM-L6-v2 (英文嵌入)。
    *   **向量数据库**: ChromaDB, FAISS (本地部署简单), Milvus (大规模场景)。
*   **数据处理与集成**:
    *   **Python数据处理**: Pandas, Polars。
    *   **ETL/数据连接**: SQLAlchemy (数据库ORM), Requests (API调用), Beautiful Soup (网页解析)。
    *   **数据库**: SQLite (本地Demo), PostgreSQL, MySQL。
*   **前端/UI**:
    *   **快速原型**: Streamlit, Gradio (适合快速构建数据驾驶舱Demo)。
    *   **Web框架**: Flask, FastAPI (后端API), React/Vue (前端框架)。
*   **数据可视化**:
    *   Plotly, Matplotlib, Seaborn, Echarts (用于图表和驾驶舱可视化)。
*   **深度学习框架**: PyTorch, TensorFlow (如果你选择训练或微调特定模型)。
