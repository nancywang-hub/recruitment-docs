## ⚠️ 重要说明

1. **AI 辅助声明**：所有候选人的笔试实战题均借助 AI 工具完成，面试中需重点验证独立完成度和真实理解程度。

2. **必问问题**：
   - "代码中哪一部分是你独立写的，哪一部分是 AI 辅助的？"
   - "如果让你从零开始（不能用 AI 辅助），你还能复现这个系统吗？"
   - "120 小时内时间是如何分配的？遇到的最大卡点是什么？"

3. **诚实度评估**：观察候选人是否如实说明 AI 辅助范围，不夸大独立贡献。
